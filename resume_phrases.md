# Формулировки для резюме

Все три варианта явно описывают учебный проект и синтетические данные.

1. Разработал учебный проект продуктовой аналитики на синтетических событиях: спроектировал PostgreSQL-схему, построил последовательную 7-дневную воронку и сверил SQL-метрики с pandas.

2. Для симуляции A/B-теста рассчитал объём выборки по baseline, MDE, α и мощности; реализовал SRM-проверку, двусторонний тест двух долей и 95% интервал Ньюкомба без заявлений об эффекте реального продукта.

3. Реализовал когортное удержание D1/D7 по UTC-календарным датам и добавил тесты на порядок событий, границы окна, зрелость когорт и повторные события пользователя в синтетическом журнале.
